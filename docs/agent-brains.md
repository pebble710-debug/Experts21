# Agent Brains: Models, Personalities, and Knowledge Folders

- **Updated:** 2026-11-24 (Step 7)
- **Agents:** 26. **Models:** `opus` × 12, `sonnet` × 12, `haiku` × 2.
- Each agent's model is set in the `model:` field of `.claude/agents/<agent-name>.md`. Its personality is in that file's `## Identity` section, and its knowledge folder is `knowledge/<agent-name>/`.

## How models were chosen

| Model | Used for | Agents |
|---|---|---|
| `opus` | Complex strategy, financial, legal, regulatory, and critical decisions; coordination and agent design | 12 |
| `sonnet` | Most specialist work: analysis, planning, design, writing | 12 |
| `haiku` | Simpler research and routine, high-volume tasks | 2 |

Notes:

- `opus`, `sonnet`, and `haiku` are Claude Code model aliases. Each runs the current version of that model family available to your account.
- The orchestrator is told **not** to pass its own model when it calls a specialist, so each specialist runs on the model assigned below.
- An administrator can override all of these with the `CLAUDE_CODE_SUBAGENT_MODEL` and `CLAUDE_CODE_SUBAGENT_MODEL_FORCE` settings, or an organization model allowlist. Run `/tasks` while an agent is working to see which model it is using.

## Talking to an expert by first name

First names are personas that set each expert's tone. To call an expert, use its **agent name**, for example `@agent-lease-negotiation-specialist`. In plain language you can also say "Ask Marcus (the lease-negotiation-specialist) to…".
